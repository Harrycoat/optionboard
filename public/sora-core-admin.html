관리자 CORE 가상매수

가상매매 전용. 실제 증권 주문은 발생하지 않습니다. SORA 공식 10개 계좌의 관리자 가상매수 입력 화면입니다. 관리자 인증 및 저장소 설정 전에는 저장되지 않습니다.

비밀번호는 브라우저에 저장하지 않으며 서버 요청 시 HTTPS로만 전송합니다. 공개된 PC에서는 사용하지 마세요.

관리자 비밀번호 변경

현재 비밀번호는 데이터베이스가 아닌 Vercel Preview 환경변수의 SHA-256 해시로 관리됩니다. 새 비밀번호는 이 브라우저에서만 해시화하며, 서버가 자동으로 변경하지는 않습니다. 아래 결과를 Vercel 환경변수에 적용해야 변경됩니다.

비밀번호를 입력하고 해시 만들기를 눌러 주세요.

복사한 해시값은 Vercel → optionboard → Settings → Environment Variables → SORA_ADMIN_PASSWORD_SHA256의 Preview 값에 입력하고 개발 Preview를 재배포해야 적용됩니다. 비밀번호는 채팅에 보내지 마세요.

관리자가 입력한 가격은 시장 검증 시세가 아니라 수동 가상체결 가격입니다. 저장 시각은 서버 UTC입니다.
