GEXOption Live Monitor 사용법

무료 회원용 15분 지연 Live Monitor의 각 컬럼과 상태값, 관심종목 추가·삭제 방법을 설명합니다.

콘텐츠 이용 안내 — 이 글은 GEXOption의 지표와 화면을 이해하기 위한 교육 자료입니다. Wall·HULL21·거래량 상태는 시장 구조를 요약하는 관찰 신호이며, 특정 거래를 지시하거나 결과를 보장하지 않습니다. 무료 회원용 Live Monitor 예시는 15분 지연 데이터를 기준으로 설명합니다.

1. Live Monitor의 목적

관심종목 여러 개를 한 화면에서 빠르게 비교해 Call Wall, Put Wall, HULL21, 거래량 방향, 현재 상태를 확인하는 도구입니다.

2. 각 컬럼의 의미

현재가 — 15분 지연 가격
Call Wall / Put Wall — 옵션 포지셔닝 기준 레벨
Put / Current / Call — 현재가가 두 Wall 사이 어디에 있는지 시각화
HULL21 — ▲ UP / → FLAT / ▼ DOWN
거래량 추세 — 현재 5분봉 vs 직전 5분봉
상태 — HOLD, ADD WATCH, HEDGE WATCH, CALL REJECTION, HULL21 BREAK, HEDGE READY, BREAKOUT

3. 관심종목 추가와 삭제

로그인 후 상단 TICKER 입력칸에 종목을 넣고 + MONITOR를 누르면 목록에 추가됩니다. 각 행 오른쪽 X 버튼으로 삭제할 수 있습니다.

4. 상태값은 어떻게 읽나?

ADD WATCH Put Wall 부근에서 HULL21 UP + 거래량 증가. HEDGE WATCH Call Wall 근처에서 추세 약화. HEDGE READY Call Wall 거절과 HULL21 이탈이 함께 확인된 상태입니다.

5. TRACK 버튼

특정 종목을 더 자세히 보고 싶을 때 TRACK을 눌러 상세 Trade Tracker로 이동합니다.

Live Monitor = 발견/감시, Trade Tracker = 상세 확인으로 역할을 나누면 화면이 복잡해지지 않습니다.

6. 데이터 지연 안내

무료 회원용 Live Monitor는 15분 지연 데이터입니다. 빠른 주문 실행용이 아니라 구조 확인과 학습용으로 사용해야 합니다.

이 페이지는 교육 목적의 설명입니다. 옵션·주식 거래에는 손실 위험이 있으며, 특정 종목의 매수·매도 권유가 아닙니다.
