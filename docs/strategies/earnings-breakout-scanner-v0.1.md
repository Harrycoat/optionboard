# STRATEGY-01 — 실적 돌파 후보 검색 (v0.1)

상태: 교육·스캐너 설계 초안. 실제 검색기 연결 및 검증은 미완료.
출처: 사용자가 제공한 「실적 돌파 매매법 가이드」 (8페이지).
상위 원칙: GEXOption 트레이딩 규칙 / SWING 및 CORE 구분.

## 책임 경계

GEXOption은 **조건에 맞는 종목을 발견하고 근거와 미확인 정보를 보여주는 도구**이다.
자동 주문, 매수 권유, 임의 손절·익절, 수익 보장, 전략 자동 실행은 범위 밖이다.
최종 매매 결정과 위험 관리는 투자자가 한다.

## 관찰할 3개 패턴

- EB-01: 실적·중요 뉴스 → 갭 상승·거래량 급증 → 지지선까지 눌림 → 반등 관찰.
- EB-02: 강한 양봉·거래량 확대 → 2일 상승 및 횡보 → 상단 재돌파 관찰.
- EB-03: 급등 후 약 3주 내외 횡보 → 박스 상단 재돌파 관찰.

## 예비 검색 조건 (가이드 인용, 백테스트 검증 전)

- 실적 발표 또는 기업가치에 영향을 주는 재료 확인 (뉴스/공시 출처와 시각 필요)
- 전일 종가 대비 +5% 이상 가격 상승
- 기준 거래량 대비 +300% 이상 증가 (평균 산정 구간·RVOL 정의 미확정)
- 완료된 일봉으로 갭/돌파와 후속 패턴 확인
- 종목별 후보 상태: 관찰 / 조건 미충족 / 데이터 부족 / 정의 미확정

## 검색 결과 스키마

ticker, pattern_id, event_type, event_date, evidence_source, bar_asof, market_data_delay,
gap_pct, price_change_pct, volume_vs_baseline_pct, breakout_level, support_level,
matched_conditions, unmet_conditions, unknown_conditions, candidate_status.

수치·거래량·뉴스는 확인 가능한 출처가 없으면 UNKNOWN으로 표기.
+300%는 '기준보다 300% 증가'와 '기준의 300%'가 다르므로 계산 정의 확정 전 혼용 금지.
변동성·급등 종목의 갭 리스크를 강조하고 과거 예시의 수익을 일반화하지 않는다.

## 운영 정책

- 사용자 지정 100종목을 기본 검색 대상(목록·선정 기준은 별도 관리).
- 실적 돌파는 전략 라이브러리의 독립 스캐너로 관리.
- 모델은 어떤 조건으로 검색됐는지 설명만 하고 진입 여부를 대신 결정하지 않는다.
- 실제 구현, 지연 데이터 품질, 재현 가능한 테스트 결과는 별도 검증 필요.
