# 소라 대화 교육 100문답 (VF-0.2 기준)

교육용 예시 답변이며 실제 시세·수익 보장·시험 통과 기록이 아니다. 일반 질문은 2~5줄, 인사에는 인사만. 퀴즈 요청이 없으면 시작하지 말 것. R01 오답은 힌트 → 재질문 → 학생 재답변 → 피드백. VF-0.2가 최우선. 예문은 정답 문구 복제가 아닌 의미 학습용이다.

## 지표

31. **Q:** SMA50은?
   **A:** 최근 50개 봉의 종가를 단순 평균한 선이에요.

32. **Q:** EMA는?

33. **Q:** Hull21은?

34. **Q:** Hull20과 Hull21 밴드는 같아?
   **A:** 아니요. 다른 지표로 구별해야 해요.

35. **Q:** Smooth는?

36. **Q:** Smooth 상승이면 무조건 매수?

37. **Q:** Net Delta는?
   **A:** 일반적으로 공격적 매수 체결량에서 공격적 매도 체결량을 뺀 값이에요.

38. **Q:** Cum Delta는?
   **A:** 체결 델타를 시간에 따라 누적한 값이에요.

39. **Q:** RVOL은?

40. **Q:** 지표 값 없으면?
   **A:** 확인 불가로 표시하고 수치를 지어내지 않아요.


## 수급 R01

41. **Q:** 매수세 둔화는 매도세 발생이야?
   **A:** 아니요. 매수세의 감소와 매도세의 증가는 별개예요.

42. **Q:** 매수세 둔화에도 상승해?
   **A:** 네. 다른 조건에 따라 상승이 지속될 수 있어요.

43. **Q:** 매도세 발생은 어떻게 확인해?
   **A:** 매도 압력이 실제로 증가했는지 별도로 봐야 해요.

44. **Q:** 수급 7단계는 절대 법칙이야?
   **A:** 아니요. 설명을 위한 순환 모형이며 예측 보장은 아니에요.

45. **Q:** 매수세 증가 속도만 줄었어.
   **A:** 매도세 증가가 확인되기 전에는 매도 우세로 단정하지 않아요.

46. **Q:** 매수와 매도 압력이 모두 약해.
   **A:** 방향을 단정하지 않고 가격과 거래량을 더 확인해요.

47. **Q:** 매수세 90이면 반드시 올라?
   **A:** 아니요. 확률과 방향을 보장하지 않아요.

48. **Q:** 가격은 오르는데 Delta가 떨어져.
   **A:** 괴리가 있을 수 있으니 후속 봉과 데이터 신뢰도를 확인해요.

49. **Q:** R01 문제 하나 내줘.
   **A:** 가상 사례: 매수 우위는 유지되지만 증가 속도가 줄었고 매도세 증가는 미확인입니다. 매수세 둔화일까요, 매도세 발생일까요?

50. **Q:** 학생: 매수세가 줄었으니 매도세가 강해졌어요.

60. **Q:** 후보 선정은 매수 권유야?
   **A:** 아니요. 교육용 관찰 후보이고 매매 결정은 투자자에게 있어요.

## VF-0.2 헤지

71. **Q:** Protective Put은?
   **A:** 보유 주식의 하락 위험 완화를 위해 풋을 사는 전략이에요.

72. **Q:** R05는?
   **A:** Call Wall 저항 및 수급 악화 조건에서 주식을 유지하며 보호 풋 BUY TO OPEN을 검토해요.

73. **Q:** R05는 3봉 꼭 기다려?
   **A:** 아니요. 3봉 의무 대기는 폐기됐어요.

74. **Q:** R05는 Smooth 하락이 필수야?
   **A:** 아니요. 새 필수 조건으로 만들지 않아요.

75. **Q:** R06은?
   **A:** 큰 거래량으로 Call Wall을 상향 돌파하면 보유 풋 SELL TO CLOSE를 검토해요.

76. **Q:** R07은?
   **A:** 상승 전환이 회복되면 풋 청산을 검토하고, 실현 순이익이 있으면 증주를 검토할 수 있어요.

77. **Q:** R08은?
   **A:** 섹터 동반 약세, 매수 약화, 매도 확대, Smooth 악화 시 주식 청산을 검토해요.

78. **Q:** R08의 SMA50 이탈 필수?
   **A:** 아니요. 필수 조건이 아니에요.

79. **Q:** 델타 0.30 숏콜 한 계약은 100주 헤지?
   **A:** 아니요. 단순 델타 환산상 약 30주 상당이고 고정 수치가 아니에요.

80. **Q:** 보호 풋은 손실이 없어?
   **A:** 아니요. 프리미엄 비용과 만기 위험이 있어요.
